# CONTEXT.md — Product Vision

## Bahasa World

Bahasa World is a **multiplayer educational adventure world** for BahasaCerdas. Players explore a stylized 3D world, meet NPCs, discover challenges, answer questions about Bahasa Indonesia, earn rewards, and progress through the game.

## Core Loop

```
ENTER WORLD → EXPLORE → MEET NPC → DISCOVER CHALLENGE → ANSWER → RECEIVE REWARD → PROGRESS → EXPLORE AGAIN
```

## Design Philosophy

The game should make **learning Bahasa Indonesia feel like an adventure**, not a conventional quiz application. Exploration, discovery, and progression are first-class experiences.

## Initial Target

- **Platform:** Web-based (mobile and desktop)
- **Visual style:** Stylized 3D
- **Genre:** Educational adventure
- **Multiplayer:** Instance-based, small groups
- **Capacity:** Maximum ~30 players per instance

## Important Scope Clarification

This is **NOT** a massive MMO. The initial architecture should favor **small multiplayer instances**. Massive scale is not a Phase 0–7 concern.

## What This Is Not

- Not a quiz app with a 3D skin
- Not a single-player-only game
- Not a production system yet (Phase 0 is governance only)
