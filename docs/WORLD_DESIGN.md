# WORLD_DESIGN.md — Bahasa Village

## First World: Bahasa Village

Bahasa Village is the starting world. It is a compact, dense, stylized 3D fantasy village inspired by Indonesian culture and aesthetics.

## Conceptual Zones

| Zone | Description |
|------|-------------|
| Alun-alun | Central village square. Main gathering and spawn point. |
| Village Houses | Residential area with NPCs and basic quests. |
| Library | Knowledge hub. NPC teachers, learning-focused challenges. |
| Forest | Exploration zone. Monster encounters, hidden paths. |
| River | Scenic boundary. Fishing NPC, bridge crossings. |
| Bridges | Connect zones. Some lead to secret areas. |
| Arena | Challenge zone. Monster battles, boss fights. |
| Monster Area | Higher-density monster zone. Greater rewards. |
| Mountain / Advanced Area | Late-game zone. Unlockable via progression. |
| World Gate | Gateway to future worlds. Locked initially. |

## Design Principles

### Visual Style
- **Stylized 3D fantasy adventure** — not realistic, not pixel art.
- **Colorful and cozy** — inviting for all ages.
- **Adventurous** — hints of danger and discovery.
- **Indonesian-inspired** — architecture, flora, cultural elements.
- **Readable silhouettes** — characters and objects are instantly recognizable.

### Technical Constraints
- **Mobile/web friendly** — performant on mid-range devices.
- **Compact and dense** — not a huge empty map.
- **Points of interest every ~15–30 seconds** of exploration.
- **Multiple player spawn areas** — distributes players across the village.

### Secrets and Discovery
- Hidden paths behind buildings or in the forest.
- Secret NPCs in unexpected locations.
- Lore fragments scattered throughout.
- Unlockable areas gated by progression.
